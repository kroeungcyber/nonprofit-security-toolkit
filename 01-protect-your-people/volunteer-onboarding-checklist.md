# ✅ Volunteer Onboarding Checklist

**A step-by-step process for securely adding new volunteers to your systems.**

---

## Why This Matters

Every new volunteer needs access to tools and information to do their work. But if you don't have a standard process, you might:
- Forget to give them access to something they need
- Give them access to things they shouldn't see
- Forget to document what they have access to
- Leave security gaps

**This checklist ensures every volunteer gets the right access, securely.**

---

## Before the Volunteer Starts

### 1. Create a Volunteer Record (5 minutes)

**Information to collect:**
- [ ] Full name
- [ ] Personal email address
- [ ] Phone number
- [ ] Emergency contact
- [ ] Start date
- [ ] Role/position
- [ ] Expected duration (ongoing, 3 months, etc.)

**Where to store:**
- Add to your volunteer database
- Include in your [asset inventory](../05-keep-good-records/README.md)

---

### 2. Determine What Access They Need (10 minutes)

**Review their role and decide:**

| System/Access | Yes/No | Notes |
|---------------|:------:|-------|
| Email account (name@yourorg.org) | ☐ | |
| Google Workspace (Drive, Docs, Calendar) | ☐ | |
| Social media accounts | ☐ | Which ones? |
| Donor database/CRM | ☐ | Read-only or full access? |
| Financial systems | ☐ | Usually only for treasurers |
| Website admin | ☐ | |
| Shared password vault | ☐ | Which collections? |
| Office keys/badge | ☐ | |
| Software licenses | ☐ | Which programs? |

**Principle:** Give the minimum access needed for their role. You can always add more later.

---

### 3. Prepare Accounts and Access (15 minutes)

**Create accounts:**
- [ ] Create email account (name@yourorg.org)
- [ ] Add to Google Workspace (if applicable)
- [ ] Create accounts in other systems (CRM, website, etc.)
- [ ] Add to shared password vault with appropriate permissions

**Prepare hardware (if providing):**
- [ ] Assign laptop/computer (record serial number)
- [ ] Set up phone/tablet (if applicable)
- [ ] Prepare any other equipment

---

## On the First Day

### 4. Security Setup (30 minutes)

**Set up password manager:**
- [ ] Help them create a Bitwarden account
- [ ] Have them install on their devices
- [ ] Show them how to use it
- [ ] Have them change their email password to a strong, unique one

**Set up two-factor authentication:**
- [ ] Help them install an authenticator app
- [ ] Enable 2FA on their email account
- [ ] Store backup codes securely

**Device security (if using organization equipment):**
- [ ] Ensure automatic updates are enabled
- [ ] Set up screen lock with password/PIN
- [ ] Enable "Find My Device" / "Find My Mac"
- [ ] Install any required security software

---

### 5. Access and Training (20 minutes)

**Share necessary passwords:**
- [ ] Add them to appropriate Bitwarden collections
- [ ] Show them how to access shared passwords
- [ ] Explain which passwords are shared vs. personal

**System training:**
- [ ] Walk through email setup
- [ ] Show Google Drive structure
- [ ] Explain file naming and organization
- [ ] Show how to access the donor database (if applicable)
- [ ] Review social media posting guidelines (if applicable)

**Security training:**
- [ ] Review [phishing awareness guide](../02-secure-your-email/volunteer-training-guide.md)
- [ ] Explain how to report suspicious emails
- [ ] Review acceptable use policy
- [ ] Explain what to do if they suspect a security issue

---

### 6. Documentation (10 minutes)

**Update records:**
- [ ] Add them to volunteer contact list
- [ ] Record what accounts they have access to
- [ ] Record what equipment they received
- [ ] Note who their supervisor/mentor is
- [ ] Add to relevant email distribution lists

**Create an access record:**

```
Volunteer Name: _____________________
Start Date: _____________________
Role: _____________________

ACCOUNTS:
- Email: _____________________
- Google Workspace: _____________________
- CRM/Database: _____________________
- Social Media: _____________________
- Website: _____________________
- Other: _____________________

EQUIPMENT ASSIGNED:
- Laptop: Serial # _____________________
- Phone: _____________________
- Other: _____________________

BITWARDEN ACCESS:
- Collections: _____________________
- Permission level: _____________________

SUPERVISOR: _____________________
SETUP COMPLETED BY: _____________________
DATE: _____________________
```

---

## During the First Week

### 7. Follow-Up (15 minutes)

**Check in with the volunteer:**
- [ ] Can they access everything they need?
- [ ] Any questions about security procedures?
- [ ] Any issues with the password manager?
- [ ] Do they understand the phishing training?

**Check systems:**
- [ ] Verify they can log into all required accounts
- [ ] Check that password sharing is working
- [ ] Ensure 2FA is set up correctly

## Supervisor Checklist

### Before Volunteer Arrives
- [ ] Determine access needed
- [ ] Create accounts
- [ ] Prepare equipment
- [ ] Assign mentor/buddy

### On First Day
- [ ] Complete security setup (password manager, 2FA)
- [ ] Provide system training
- [ ] Review security policies
- [ ] Document access granted

### End of First Week
- [ ] Confirm all access working
- [ ] Answer questions
- [ ] Document any additional access needed

---

## Access Levels Reference

### Standard Volunteer
- Email account
- Google Workspace (Drive, Calendar)
- Basic shared passwords
- Limited Drive folder access

### Team Lead / Manager
- Everything in Standard, plus:
- Full Google Drive access
- Social media access
- CRM read access
- Additional shared vault collections

### Admin / Board
- Everything in Team Lead, plus:
- Financial system access
- CRM full access
- Website admin access
- All shared vault collections

---

## Common Mistakes to Avoid

❌ **Don't:** Give admin access "just in case"
✅ **Do:** Start with minimum access, add as needed

❌ **Don't:** Share passwords via email or chat
✅ **Do:** Use Bitwarden sharing or have them log in directly

❌ **Don't:** Forget to document what you gave them
✅ **Do:** Complete the access record immediately

❌ **Don't:** Skip the security training
✅ **Do:** Make sure they understand phishing before they check email

❌ **Don't:** Use personal email for work accounts
✅ **Do:** Create organization email (name@yourorg.org)
