## What Problem This Solves

Small non-profits (5-50 people) face the same cyber threats as big companies but often have:
- ❌ No dedicated IT staff
- ❌ No security budget ($0-100/year)
- ❌ Volunteers with mixed technical skills
- ✅ Valuable donor data to protect

**This toolkit provides a complete, free security program any non-profit can implement in a weekend.**

---

## 💼 Business Outcomes Delivered

| Risk Area | What Could Go Wrong | Solution Provided |
|-----------|---------------------|-------------------|
| **Phishing Attacks** | Volunteer clicks fake email, donor database stolen | Email hardening guide + volunteer training materials |
| **Password Breaches** | Reused passwords lead to account takeovers | Free password manager rollout + two-factor authentication |
| **Ransomware** | All files encrypted, operations halted | 3-2-1 backup strategy + recovery runbook |
| **Data Privacy Fines** | GDPR violation from poor data handling | Compliance checklist + privacy templates |
| **Volunteer Turnover** | Ex-staff retain access to systems | Automated onboarding/offboarding process |

## 📖 Documentation Principles

Every guide in this toolkit follows these rules:

1. **"Why This Matters" first** — Business risk explained in plain English
2. **No jargon without explanation** — Every technical term defined
3. **Specific, actionable steps** — Exact tools, buttons, and clicks
4. **Time and cost savings shown** — ROI is always clear
5. **Designed for volunteers** — Non-technical staff can follow along
