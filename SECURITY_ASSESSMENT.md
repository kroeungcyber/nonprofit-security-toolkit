# 🔍 Non-Profit Security Assessment

**A 15-minute checklist to understand your organization's security risks.**

---

## Why This Matters

Before you fix anything, you need to know what's broken. This assessment helps you:
- Understand where your organization is most vulnerable
- Prioritize what to fix first (based on risk, not what's easiest)
- Show board members or donors that you take security seriously
- Track improvement over time

**Time required:** 15-20 minutes  
**Who should do this:** Whoever manages technology decisions (even if that's not their official job)

---

## 📋 The Assessment

Go through each section. For each question, check **Yes**, **No**, or **Not Sure**.

### Section 1: Passwords & Account Security 🔐

| Question | Yes | No | Not Sure |
|----------|:---:|:--:|:--------:|
| Do all staff/volunteers use a password manager? | ☐ | ☐ | ☐ |
| Are all accounts protected with two-factor authentication (2FA)? | ☐ | ☐ | ☐ |
| Are passwords at least 12 characters long? | ☐ | ☐ | ☐ |
| Do people use different passwords for different accounts? | ☐ | ☐ | ☐ |
| Are shared accounts (like info@yourorg.org) logged in a secure place? | ☐ | ☐ | ☐ |
| Are ex-volunteer accounts disabled within 24 hours of departure? | ☐ | ☐ | ☐ |

**Scoring:**
- All Yes = ✅ Strong
- 1-2 No/Not Sure = ⚠️ Needs Attention
- 3+ No/Not Sure = 🚨 Critical Risk

**What this protects against:** Account takeovers, data breaches, unauthorized access

## 🎯 Prioritized Action Plan

### Fix These First (This Week)

These are the highest-impact, lowest-effort fixes:

1. **Enable two-factor authentication** on your most important accounts (email, banking, donor database)
2. **Set up a password manager** and start using it
3. **Turn on automatic updates** on all computers
4. **Change default router passwords**

### Fix These Next (This Month)

1. **Set up automated backups** for critical data
2. **Deploy email security** (SPF/DKIM/DMARC)
3. **Create an asset inventory**
4. **Train volunteers** on phishing recognition

### Fix These Soon (Next 3 Months)

1. **Document your technology** (what you have, who has access)
2. **Create incident response procedures**
3. **Review and document** all software and services
4. **Set up a guest WiFi network**
